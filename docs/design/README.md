# Remote product design

`remote-rwd-concept.html` is the current reviewable product-design reference for the Avalonia desktop application.

It covers:

- adaptive wide, compact, and portrait layouts;
- independently collapsible Connection tree and inspector;
- Session display, full-screen, fit-to-window, and monitor controls;
- Connection create, edit, and delete flows;
- Vault and operational Identity Card management;
- mRemoteNG one-time import;
- settings, audit, and remote-monitor selection;
- View Only status and protocol-scoped credentials.

Open the HTML file directly in a browser. Treat approved changes in this document as the presentation reference for `src/Remote.Desktop`; domain and security behavior remains authoritative in `CONTEXT.md` and the ADRs.
